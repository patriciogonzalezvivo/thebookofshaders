## ivec2
2-wymiarowy wektor całkowitoliczbowy

### Deklaracja
```glsl
ivec2 aIvec2 = ivec2(1, 1);
ivec2 bIvec2 = ivec2(1);

ivec2 cIvec2 = ivec2(aIvec3);
ivec2 dIvec2 = ivec2(aIvec3.x, aIvec3.y);
```

### Opis
```ivec2``` to wektor całkowitoliczbowy mający dwie składowe. Można go zainicjalizować:

- Podając wartość skalarną dla każdej składowej.
- Podając jedną wartość skalarną. Wartość ta zostanie użyta dla wszystkich składowych.
- Podając wektor o wyższym wymiarze. Odpowiednie wartości zostaną użyte do inicjalizacji składowych.
