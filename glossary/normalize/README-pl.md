## normalize
Oblicza wektor jednostkowy o tym samym kierunku co wektor wejściowy

### Deklaracja
```glsl
float normalize(float x)
vec2 normalize(vec2 x)
vec3 normalize(vec3 x)
vec4 normalize(vec4 x)
```

### Parametry
```x``` określa wektor do znormalizowania.

### Opis
```normalize()``` zwraca wektor o tym samym kierunku co jego parametr ```x```, ale o długości 1.
