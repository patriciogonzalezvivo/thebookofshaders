## log
Zwraca logarytm naturalny podanego parametru

### Deklaracja
```glsl
float log(float x)
vec2 log(vec2 x)
vec3 log(vec3 x)
vec4 log(vec4 x)
```

### Parametry
```x``` określa wartość, z której ma zostać obliczony logarytm naturalny.

### Opis
```log()``` zwraca logarytm naturalny ```x```.
