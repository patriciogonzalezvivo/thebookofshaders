## void

### Deklaracja
```glsl
void main(void);
int aFunction(void);
void bFunction(float);
```

### Opis
```void``` używane jest wtedy, gdy funkcja nie przyjmuje żadnych parametrów lub gdy funkcja nie zwraca żadnej wartości.
