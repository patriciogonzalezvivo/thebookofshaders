## length
Oblicza długość wektora

### Deklaracja
```glsl
float length(float x)
float length(vec2 x)
float length(vec3 x)
float length(vec4 x)
```

### Parametry
```x``` określa wektor, którego długość ma zostać obliczona.

### Opis
```length()``` zwraca długość wektora.
