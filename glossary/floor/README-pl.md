## floor
Znajduje najbliższą liczbę całkowitą, która jest mniejsza lub równa podanemu parametrowi

### Deklaracja
```glsl
float floor(float x)
vec2 floor(vec2 x)
vec3 floor(vec3 x)
vec4 floor(vec4 x)
```

### Parametry
```x``` określa wartość do ewaluacji.

### Opis
```floor()``` zwraca wartość równą najbliższej liczbie całkowitej, która jest mniejsza bądź równa ```x```.
