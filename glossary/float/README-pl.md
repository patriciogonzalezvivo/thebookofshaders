## float
Zmiennoprzecinkowy typ zmiennej

### Deklaracja
```glsl
float aFloat = 1.0;
float bFloat = float(aBool);
float cFloat = float(aInt);
```

### Opis
```float``` służy do przechowywania wartości zmiennoprzecinkowych.
