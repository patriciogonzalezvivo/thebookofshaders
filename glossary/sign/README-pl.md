## sign
Zwraca znak podanego parametru

### Deklaracja
```glsl
float sign(float x)
vec2 sign(vec2 x)
vec3 sign(vec3 x)
vec4 sign(vec4 x)
```

### Parametry
```x``` określa wartość, której znak ma zostać zwrócony.

### Opis
```sign()``` zwraca -1.0, jeśli ```x``` jest mniejsze od 0.0, 0.0, jeśli ```x``` jest równe 0.0, oraz +1.0, jeśli ```x``` jest większe od 0.0.
