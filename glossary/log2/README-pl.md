## log2
Zwraca logarytm o podstawie 2 podanego parametru

### Deklaracja
```glsl
float log2(float x)
vec2 log2(vec2 x)
vec3 log2(vec3 x)
vec4 log2(vec4 x)
```

### Parametry
```x``` określa wartość, z której ma zostać obliczony logarytm o podstawie 2.

### Opis
```log2()``` zwraca logarytm o podstawie 2 z ```x```.
