## tan
Zwraca tangens podanego parametru

### Deklaracja
```glsl
float tan(float angle)
vec2 tan(vec2 angle)
vec3 tan(vec3 angle)
vec4 tan(vec4 angle)
```

### Parametry
```angle``` określa wartość (w radianach), dla której ma zostać zwrócony tangens.

### Opis
```tan()``` zwraca trygonometryczny tangens podanego kąta.
