## sqrt
Zwraca pierwiastek kwadratowy podanego parametru

### Deklaracja
```glsl
float sqrt(float x)
vec2 sqrt(vec2 x)
vec3 sqrt(vec3 x)
vec4 sqrt(vec4 x)
```

### Parametry
```x``` określa wartość, z której ma zostać obliczony pierwiastek kwadratowy.

### Opis
```sqrt()``` zwraca pierwiastek kwadratowy z ```x```.
