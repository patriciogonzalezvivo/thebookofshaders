## not
Neguje logicznie wektor logiczny

### Deklaracja
```glsl
bvec2 not(bvec2 x)
bvec3 not(bvec3 x)
bvec4 not(bvec4 x)
```

### Parametry
```x``` określa wektor do zanegowania.

### Opis
```not()``` neguje logicznie wektor logiczny ```x```. Zwraca nowy wektor logiczny, w którym każdy element ```i``` obliczany jest jako ```!x[i]```.
