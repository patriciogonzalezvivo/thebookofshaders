## exp2
Zwraca 2 podniesione do potęgi równej podanemu parametrowi

### Deklaracja
```glsl
float exp2(float x)
vec2 exp2(vec2 x)
vec3 exp2(vec3 x)
vec4 exp2(vec4 x)
```

### Parametry
```x``` określa wykładnik potęgi, do której zostanie podniesiona liczba 2.

### Opis
```exp2()``` zwraca 2 podniesione do potęgi ```x```.
